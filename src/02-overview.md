# 2. 系统总览

## 2.1 定位

KMiri 是基于 Miri 的 Rust 内核执行与检查环境：为选定的内核操作提供解释器能够理解的执行语义，并检查相关 Rust 执行中的未定义行为。

## 2.2 组件构成

* kmiri：基于 Miri 的解释器扩展，负责内核执行环境与原有检查机制的对接。
* MIR Debugger：交互式调试工具，用于观察 MIR 执行位置、调用栈、内存对象和检查状态，辅助分析执行过程及错误原因。
