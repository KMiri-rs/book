# 5. 检查能力与错误模型

## 5.1 继承自 Miri 的检查项

● 越界访问、释放后使用，以及其他无效内存访问。

● 不满足要求的内存对齐。

● 非法使用未初始化数据。

● 无效类型值，例如不符合 bool 或枚举取值要求的数据。

● 指针来源与访问有效性检查，以及所选借用模型下的别名检查。

● 数据竞争检查。
